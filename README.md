# Monster Garden Roguelite (working title TBD)

Design documents for a mobile creature-collector roguelite: raise monsters in a safe garden, train them for competitions they play out themselves, and decide which ones to risk. In lethal cups, losers "go to the Heap".

## Contents

| File | What it is |
| --- | --- |
| [docs/GDD.md](docs/GDD.md) | Main game design document: vision, core loops, monsters, competitions, fusion, Renown, online, economy, tech, roadmap, risks |
| [docs/Monster-Bible.md](docs/Monster-Bible.md) | Monster families, art style, parts, balance matrix, evolution forms and the design process |
| [docs/images/](docs/images/) | Snapshots of the doc's diagrams (core loop, roadmap, monster anatomy) |
